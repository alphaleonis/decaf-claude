2. **`src/services/textChanges.ts:1339`** (confidence 75, Medium) — `getFormattedTextOfNode` builds an ad hoc `SourceFileLike` (`{ text, getLineAndCharacterOfPosition }`) that never sets the new `languageVariant` field this PR introduced. Because the synthetic object lacks `languageVariant`, `createChildren` falls back to `Standard`, so JSX content generated/formatted by codefixes and refactors (via `ChangeTracker`) still hits the exact mis-scan class this PR set out to fix — this construction site was simply missed.
