**1. `src/Microsoft.Data.Sqlite.Core/SqliteDataRecord.cs:393` — `Debug.Assert(rowIdForOrdinal!=null)` reintroduces an invariant the rewrite no longer guarantees, crashing on legitimate "no rowid" cases.**

- Description: The pre-PR code seeded `_rowidOrdinal = -1` as a sentinel *before* the scan loop, so `_rowidOrdinal.HasValue` was unconditionally true afterward regardless of whether a rowid was actually found — making `Debug.Assert(_rowidOrdinal.HasValue)` a tautology by construction. The PR's rewrite replaces the sentinel with `rowIdForOrdinal` staying `null` when no rowid is found, then asserts it is non-null anyway (`Debug.Assert(rowIdForOrdinal!=null)`, line 393) even though `null` is an explicitly and correctly handled outcome three lines later (`if (rowIdForOrdinal == null) return new MemoryStream(...)`, line 396). This turns a previously-vacuous sanity check into a real, violatable invariant.
- Concrete failure scenario: `SELECT 'test';` then `reader.GetFieldValue<TextReader>(0)` (exercised by the pre-existing test `GetFieldValue_of_TextReader_works` in `test/Microsoft.Data.Sqlite.Tests/SqliteDataReaderTest.cs:1000`). The single result column has no backing table (a literal expression), so `blobTableName`/`blobDatabaseName` are empty and the scan loop's only column is skipped via `i == ordinal → continue`. `rowIdForOrdinal` stays `null`, and `Debug.Assert` fails, crashing the process in Debug builds (as reported in issue #32944's stack trace, which points at this exact line).
- Reason flagged: historical git context. This is not speculative — it is the documented, verified real-world cause of this exact PR being reverted (PR #32945 → issue #32944 → re-fix PR #33111). PR #33111's fix is byte-for-byte identical to this diff except that this one line is commented out with the explanatory note: `//debug assertion no more needed: rowIdForOrdinal == null => matching rowid not found, MemoryStream returned; rowIdForOrdinal != null => matching rowid found, SqliteBlob returned.` The PR's own commit history (`git log`/PR commits: "blob fix...", "test case...", "assert readded") shows the author re-added this exact assert in a late commit (`f08c4cfc5`, "assert readded"), unaware that the sentinel guarantee it depended on had been removed by the dictionary-based rewrite.

**2. `src/Microsoft.Data.Sqlite.Core/SqliteDataRecord.cs:329-393` — loss of negative-result caching (performance regression vs. established invariant).**

- Description: The original design (established in commit `4e0dcfc0c`, "Handle composite keys in SqliteDataReader.GetStream()", and reinforced by `79e481121`, "Add Ordinal and Name Caching to SqliteDataRecord") deliberately cached *both* the "found" and "not found" outcomes: setting `_rowidOrdinal = -1` up front ensured the expensive scan (looping all `FieldCount` columns plus a `pragma_table_info` query per INTEGER-PK candidate) ran at most once per `SqliteDataRecord`, whichever the outcome. In the rewrite, `RowIds.Add(rowidkey, rowIdForOrdinal)` is only called inside the two "found" branches (lines 355, 387) — there is no code path that ever caches a negative ("no rowid for this table") result under `rowidkey`.
- Concrete failure scenario: repeatedly calling `GetStream`/`GetTextReader`/`GetFieldValue<Stream>` on any blob column belonging to a table with no usable single-column INTEGER PRIMARY KEY (e.g., a `WITHOUT ROWID` table, a composite-PK table, or an expression/literal column as above) will re-run the full linear column scan — and re-issue the `pragma_table_info` SQL query for every INTEGER-PK candidate encountered — on *every single call*, instead of once per record, silently reintroducing the O(n) rescanning cost the caching mechanism existed to eliminate.
- Reason flagged: historical git context. The `_rowidOrdinal = -1`-before-loop pattern in the pre-PR code is not incidental — it's the deliberate caching invariant from `4e0dcfc0c` onward, and this rewrite drops it for the "not found" case while preserving it for the "found" case, an inconsistency not present, and seemingly not intended, in the original design.
