## Considered But Not Flagged

- **Poll `err` vs `pollErr` return contract (node.go L82-109).** Traced every path: the poll closure returns `(false, nil)` on failure and `(true, nil)` on success; each `return false` branch first assigns a non-nil `err` (Get failure, GetNodeHostIPs failure, or the PodCIDR check). `PollUntilContextCancel` (immediate=true) runs the condition at least once, and only returns non-nil `pollErr` after a false iteration or ctx cancellation — in both cases the last-run condition left `err` non-nil. So `if pollErr != nil { return nil, err }` cannot return `(nil, nil)`. Contract holds; not a bug. Uses `=` (not `:=`) so no shadowing.

- **`n.node = node` storing informer-owned pointer without DeepCopy (OnNodeChange L145).** Idiomatic: k8s handlers may retain informer objects as long as they only read them; NodeManager reads only, and Node() DeepCopies on the one path that hands the object outward. The sole real escape is via PodCIDRs() (flagged above).

- **Shared topology map passed to all handlers (config.go L535).** `handleNodeEvent` allocates a fresh map each event and passes the same reference to every registered handler; metaProxier fans it to ipv4+ipv6 proxiers which store it under their own mutex. No handler mutates the map and the config replaces (never mutates) it, so the aliasing is read-only. Informer event handlers are invoked serially, so `n.topologyLabels`/`n.eventHandlers` need no lock. Safe.

- **nil-map reads in CategorizeEndpoints (topology.go L58).** When a node has no zone label, DeepEqual short-circuits and proxiers never receive an OnTopologyChange, leaving proxier.topologyLabels nil. `topologyLabels[v1.LabelTopologyZone]` on a nil map is a safe read returning "". No nil-map writes exist anywhere on this surface.

- **Discarded errors `oldNodeIPs, _ :=` / `nodeIPs, _ :=` (node.go L123, L143).** The node object was validated to have host IPs during construction, so these discards are intentional and safe.

- **`reflect.DeepEqual` on PodCIDRs/NodeIPs slices (node.go L151, L167).** Order is deterministic (GetNodeHostIPs and PodCIDRs have stable ordering); nil-vs-empty divergence would only trigger an intended crash-on-change. Not an idiom defect.

- **Interface satisfaction for OnTopologyChange.** Verified all Provider implementors — iptables, ipvs, nftables, winkernel, metaProxier, and kubemark FakeProxier — define `OnTopologyChange(map[string]string)`; the removed NodeHandler methods (OnNodeAdd/Update, NoopNodeHandler) have no remaining callers. Consistent; compiles.

- **`NodeEligible()` nil `nodeManager` deref (proxy_health.go L180).** In newProxyServer the HealthzServer is always constructed with a non-nil NodeManager (NewNodeManager errors out otherwise), on both Linux and Windows paths. Hollow proxy leaves HealthzServer nil (never served), so `NodeEligible()` is unreachable with a nil nodeManager. Not exploitable.
