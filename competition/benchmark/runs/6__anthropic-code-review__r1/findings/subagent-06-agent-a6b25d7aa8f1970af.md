**2. `src/vs/workbench/browser/dnd.ts:238-247` — restricting `DataTransfers.TEXT` to `Schemas.file` breaks dragging remote/virtual resources into text-capable areas (terminal, search box, etc.), an explicitly documented use of this code path ("Text: allows to paste into text-capable areas").**

The PR narrows this to `nativeResources` (scheme `file` only), so dragging any resource from a remote/SSH/WSL/container workspace into an in-VS-Code text-capable target now sets no TEXT data at all. This is exactly the line the official revert restored: the auto-generated revert-PR review summary for `26d36469b0`/#323490 states "Reverts the filtering behavior for text drag data (restores prior behavior of setting text from all file-service resources)."

**3. `src/vs/workbench/contrib/files/browser/explorerService.ts:287-` (`resolveClipboardResources`) — substituting the copied resource's URI with a local temp-download path breaks same-folder duplicate/rename-on-paste for remote workspaces.**
